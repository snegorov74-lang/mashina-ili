# Машина Ильи

Сайт про радиоуправляемую машину Ильи — **Remo Hobby S-EVOR (RH1661)**, трагги 1:16, полный привод.

На сайте: паспорт машины, инструкции (зарядка, пульт, уход, неисправности), схемы сборки производителя, каталог запчастей с номерами, состояние машины, что заменено, планы покупок и журнал.

## Как обновить состояние машины

Всё про текущее состояние лежит в одном файле — [`data/garage.js`](data/garage.js).

1. Откройте файл на GitHub и нажмите карандаш (**Edit this file**).
2. Поправьте нужное:
   - `nodes` — состояние узлов: `"ok"`, `"watch"` (присмотреть), `"broken"` (сломано), `"replaced"` (заменено);
   - `replaced` — что заменили: дата, номер детали, причина, цена;
   - `plans` — что купить; когда купили, поставьте `done: true`;
   - `log` — журнал: катания, поломки, ремонты, покупки. Новые записи — сверху.
3. Нажмите **Commit changes**, затем опубликуйте изменения (см. «Публикация» ниже).

Даты пишутся как `"2026-11-02"`. Следите за кавычками и запятыми между записями.

## Каталог запчастей

[`data/parts.js`](data/parts.js) — детали по узлам с номерами из схем Remo Hobby. Пометка `weak: true` — слабое место.

## 3D-модель

`model/sevor.glb` — упрощённая модель, собранная скриптом `model/build_sevor.py` в Blender 4.5:

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b --python model/build_sevor.py
```

Если файла модели нет, на главной показывается фото.

## Публикация (деплой)

Сайт собирается GitHub Pages из ветки **`deploy`**, а работа идёт в **`main`**. Поэтому изменения в `main` на сайт сами не попадают.

Опубликовать то, что сейчас в `main` на GitHub:

```bash
scripts/deploy.sh
```

Откатить сайт на прошлую версию — указать коммит:

```bash
scripts/deploy.sh 92a9b47
```

Скрипт проверяет, что в публикуемом коммите есть все нужные файлы, и переносит его в `deploy`. Сайт обновляется через 1–2 минуты.

> Правки в `data/garage.js` через веб-редактор GitHub попадают в `main`. Чтобы они появились на сайте, запустите `scripts/deploy.sh` или отредактируйте файл сразу в ветке `deploy`.
